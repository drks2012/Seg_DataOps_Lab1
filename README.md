# Comercial Nova · Laboratorio 1

Inicia con [preparar.py](preparar.py) para generar los datos ficticios, la referencia y la clave local. Luego sigue las instrucciones de `lab1.md` para completar los TODO y ejecutar las pruebas.

Una vez completados los pasos, podrás ejecutar las pruebas y verificar los resultados siguiendo las instrucciones de `lab1.md`.

Responde las preguntas y completa las evidencias en `evidencias.md` según lo observado durante la ejecución de las pruebas.

Sube tu proyecto completo, incluyendo `lab1.py`, `comprobar_1a.py`, `evidencias.md` y cualquier salida generada, pero sin la clave ni los datos originales a un repositorio de Github.
